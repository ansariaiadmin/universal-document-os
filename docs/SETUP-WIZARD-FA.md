# جادوگر راه‌اندازی — Universal Document OS (فارسی)

**نسخه:** v3.2.5 · **مخاطب:** کاربر غیرفنی
**زمان لازم:** نصب ≈ ۵ دقیقه · اولین پردازش ≈ ۳۰ ثانیه
**قاعده این راهنما:** فقط چیزهایی نوشته شده که در نسخه فعلی *واقعاً کار می‌کنند*. وعده‌های آینده مشخص و برچسب‌دارند.

---

## ۱) این برنامه چیکار می‌کنه؟ (سه خط)

اسنادت را روی کامپیوتر خودت متن‌کشی می‌کند: فایل PDF/Word/Excel/… را می‌دهی، متن استخراج‌شده + پیش‌نمایش + فایل خروجی TXT/Markdown تحویل می‌گیری. هیچ فایلی به بیرون فرستاده نمی‌شود؛ لاگین ندارد؛ آفلاین کار می‌کند.

## ۲) نصب — فقط یک دستور

```bash
git clone https://github.com/ansariaiadmin/universal-document-os.git
cd universal-document-os
chmod +x install.sh
./install.sh
```

اگر همه‌چیز درست بود، انتهای اجرا این را می‌بینی:

```text
🌐 http://localhost:8000 — لندینگ، و http://localhost:8000/app — پنل اسناد
📚 API Docs: http://localhost:8000/api/docs
```

همین سه آدرس را بوکمارک کن. **ویندوز:** به‌جای `install.sh` روی `install.bat` دوبار کلیک کن.

### نصب چه کاری انجام می‌دهد؟ (تا نترسی!)

| مرحله | توضیح ساده |
|---|---|
| بررسی سیستم | Docker نصب است؟ دیسک جا هست؟ پورت ۸۰۰۰ آزاده؟ |
| ساخت `.env` | فایل تنظیمات با مقادیر امن ساخته می‌شود؛ مجوزش ۶۰۰ (فقط خودت می‌خوانی) |
| Build و Run | کانتینر ساخته و سرویس بالا می‌آید |
| Health Check | تا وقتی `/api/health` جواب ندهد صبر می‌کند و بعد پیام موفقیت می‌دهد |

## ۳) اولین سند — قدم‌به‌قدم

1. مرورگر → `http://localhost:8000/app`
2. فایل انتخاب کن — یکی از این‌ها: **PDF، DOCX، XLSX، PPTX، ODT، TXT، MD، CSV، JSON، HTML، RTF**
3. عملیات: «Analyze» برای فقط دیدن متن، یا «Export text» + فرمت `txt`/`md` برای گرفتن فایل دانلودی
4. دکمه Process → نتیجه: فرمت شناسایی‌شده، تعداد کاراکتر، پیش‌نمایش، لینک دانلود

## ۴) فرمت‌ها — جدول صادقانه

| فرمت | وضعیت | نکته |
|---|---|---|
| PDF متنی | ✅ | اگر PDF عکس/اسکن باشد متن درنمی‌آید (OCR در نسخه بعد — ROADMAP) |
| DOCX / XLSX / PPTX / ODT | ✅ | Excel مقادیر سلول‌ها را می‌دهد نه فرمول |
| TXT / MD / CSV / JSON / HTML / RTF | ✅ | بدون کتابخانه اضافه |
| DOC / XLS / PPT / ODS / ODP | ⚠️ فقط شناسایی | پیام می‌دهد؛ اول در Word/LibreOffice «Save As» فرمت جدید بگیر |
| عکس (JPG/PNG) | ⬜ هنوز نه | موتور OCR آماده ولی به API وصل نشده |

## ۵) پیام‌های رایج و معنی‌شان

- `[UNSUPPORTED_FORMAT] …` → فرمت قدیمی یا کتابخانه اختیاری نصب نیست. راه‌حل: تبدیل فایل / نصب `python-pptx odfpy`.
- `[EXTRACTION_ERROR] …` → فایل خراب یا رمزدار است. رمز فایل را بردار و دوباره بفرست.
- `file too large (413)` → بیشتر از ۲۵ مگابایت. فایل را کوچک کن یا `MAX_UPLOAD_BYTES` را در `.env` زیاد کن.
- صفحه باز نشد → `./status.sh` بعد `./logs.sh`؛ معمولاً کانتینر پایین است: `./start.sh`.

## ۶) داده‌هایم کجا می‌رود؟

```
data/uploads/    فایل اصلی آپلودی
data/outputs/    خروجی‌های txt/md قابل دانلود
data/workrooms/  رکورد هر job (چه فایلی، چه فرمتی، چند کاراکتر)
data/audit.jsonl تاریخچه append-only همه کارها
```

هیچ‌کدام به اینترنت نمی‌رود. بکاپ کامل = `./backup.sh` (۷ بکاپ آخر در `backups/` می‌ماند).

## ۷) روتین روزانه

| دستور | کار |
|---|---|
| `./start.sh` / `./stop.sh` | روشن/خاموش |
| `./status.sh` | سلامت + پورت + دیسک |
| `./logs.sh` | لاگ زنده |
| `./update.sh` | آپدیت با بکاپ خودکار |
| `./smoke-test.sh` | تست کلی |

## ۸) امنیت — همین سه قانون کافی است

1. فعلاً **لاگین ندارد** — روی اینترنت عمومی باز نکن (احراز هویت در نقشه راه v4.0).
2. `.env` را برای کسی نفرست؛ فقط `.env.example` قابل اشتراک است.
3. بکاپ‌ها را جای امن نگه دار (داخلشان `.env` هست).
