# راه‌اندازی سریع — Universal Document OS (فارسی)

**نسخه:** v4.2.0 · **مخاطب:** کاربر غیرفنی
**زمان لازم:** نصب ≈ ۵ دقیقه · اولین پردازش ≈ ۳۰ ثانیه
**قاعده این راهنما:** فقط چیزهایی نوشته شده که در نسخه فعلی *واقعاً کار می‌کنند*. وعده‌های آینده صریحاً «برنامه آینده» برچسب خورده‌اند.

---

## ۱) این برنامه چیکار می‌کنه؟ (سه خط)

اسنادت را روی کامپیوتر خودت متن‌کشی می‌کند: فایل PDF/Word/Excel/… را می‌دهی، متن استخراج‌شده + پیش‌نمایش + فایل خروجی TXT/Markdown تحویل می‌گیری. هیچ فایلی به بیرون فرستاده نمی‌شود؛ لاگین ندارد؛ آفلاین کار می‌کند.

## ۲) نصب — فقط یک دستور

```bash
git clone https://github.com/ansariaiadmin/universal-document-os.git
cd universal-document-os
chmod +x install.sh
./install.sh
```

اگر همه‌چیز درست بود، انتهای اجرا این را می‌بینی:

```text
🌐 http://localhost:8000 — لندینگ، و http://localhost:8000/app — پنل اسناد
📚 API Docs: http://localhost:8000/api/docs
```

همین سه آدرس را بوکمارک کن. **ویندوز:** به‌جای `install.sh` روی `install.bat` دوبار کلیک کن.

### نصب چه کاری انجام می‌دهد؟ (تا نترسی!)

| مرحله | توضیح ساده |
|---|---|
| بررسی سیستم | Docker نصب است؟ دیسک جا هست؟ پورت ۸۰۰۰ آزاده؟ |
| ساخت `.env` | فایل تنظیمات با مقادیر امن ساخته می‌شود؛ مجوزش ۶۰۰ (فقط خودت می‌خوانی) |
| Build و Run | کانتینر ساخته و سرویس بالا می‌آید |
| Health Check | تا وقتی `/api/health` جواب ندهد صبر می‌کند و بعد پیام موفقیت می‌دهد |

## ۳) اولین سند — قدم‌به‌قدم

1. مرورگر → `http://localhost:8000/app`
2. فایل انتخاب کن — یکی از این‌ها: **PDF، DOCX، XLSX، PPTX، ODT، TXT، MD، CSV، JSON، HTML، RTF**
3. عملیات: «Analyze» برای فقط دیدن متن، یا «Export text» + فرمت `txt`/`md` برای گرفتن فایل دانلودی
4. دکمه Process → نتیجه: فرمت شناسایی‌شده، تعداد کاراکتر، پیش‌نمایش، لینک دانلود

## ۴) فرمت‌ها — جدول صادقانه

| فرمت | وضعیت | نکته |
|---|---|---|
| PDF متنی | ✅ | اگر PDF اسکن‌شده باشد، لایه متنی ندارد (OCR صفحات PDF در ROADMAP است) |
| DOCX / XLSX / PPTX | ✅ | Excel مقادیر سلول‌ها را می‌دهد نه فرمول |
| ODT / ODS / ODP | ✅ | با کتابخانه استاندارد پایتون خوانده می‌شوند — بدون وابستگی اضافه |
| TXT / MD / CSV / JSON / HTML / RTF | ✅ | بدون کتابخانه اضافه |
| عکس (JPG/PNG/WEBP/TIFF) | ✅ OCR واقعی | در نصب داکری Tesseract با زبان انگلیسی + فارسی نصب است؛ در اجرای دستی باید خودتان نصب کنید |
| DOC (legacy) | ⚠️ با antiword | اگر باینری `antiword` نصب باشد واقعاً استخراج می‌شود؛ وگرنه پیام راهنما |
| XLS / PPT (legacy) | ⚠️ فقط شناسایی | پیام می‌دهد؛ اول در Office/LibreOffice «Save As» فرمت جدید بگیرید |

## ۵) پیام‌های رایج و معنی‌شان

- `[UNSUPPORTED_FORMAT] …` → فرمت قدیمی یا ابزار کمکی نصب نیست. راه‌حل: تبدیل فایل به فرمت مدرن.
- `[UNSUPPORTED_FORMAT] IMAGE …` → موتور OCR در دسترس نیست (فقط اجرای دستی؛ در داکر نصب است).
- `[EXTRACTION_ERROR] …` → فایل خراب یا رمزدار است. رمز فایل را بردار و دوباره بفرست.
- `content rejected (415)` → محتوا با پسوند هم‌خوان نیست یا zip-bomb است.
- `file too large (413)` → بیشتر از ۲۵ مگابایت. فایل را کوچک کن یا `MAX_UPLOAD_BYTES` را در `.env` زیاد کن.
- صفحه باز نشد → `./status.sh` بعد `./logs.sh`؛ معمولاً کانتینر پایین است: `./start.sh`.

## ۶) داده‌هایم کجا می‌رود؟

```
data/uploads/    فایل اصلی آپلودی
data/outputs/    خروجی‌های txt/md قابل دانلود
data/workrooms/  رکورد هر job (چه فایلی، چه فرمتی، چند کاراکتر)
data/audit.jsonl تاریخچه append-only همه کارها
```

هیچ‌کدام به اینترنت نمی‌رود. بکاپ کامل = `./backup.sh` — شامل **همه‌ی `data/`** (آپلودها، خروجی‌ها، رکوردها، audit و jobs.db)؛ آخرین ۷ بکاپ در `backups/` می‌ماند.

## ۷) روتین روزانه

| دستور | کار |
|---|---|
| `./start.sh` / `./stop.sh` | روشن/خاموش |
| `./status.sh` | سلامت + پورت + شمارنده‌های زنده |
| `./logs.sh` | لاگ زنده |
| `./update.sh` | آپدیت با بکاپ خودکار |
| `./backup.sh` | بکاپ واقعی از همه‌ی `data/` |
| `./smoke-test.sh` | تست سرتاسری واقعی (آپلود → استخراج → دانلود) |

## ۸) امنیت — همین سه قانون کافی است

1. پیش‌فرض **لاگین ندارد** — روی اینترنت عمومی باز نکن. برای شبکه‌ی مشترک در `.env` مقدار `UDO_API_KEYS=یک-کلید-قوی` را ست کنید تا همه‌ی APIها کلید بخواهند.
2. `.env` را برای کسی نفرست؛ فقط `.env.example` قابل اشتراک است.
3. بکاپ `./backup.sh` مقدارهای رمزی را سانسور می‌کند؛ نسخه‌ی اصلی `.env` را خودتان جداگانه و رمزنگاری‌شده نگه دارید.

## ۹) سوالات سریع

- **موبایل؟** روی همان Wi-Fi: `http://IP-کامپیوتر:8000/app` — پنل PWA دارد (Add to Home screen).
- **عکس اسکن‌شده؟** در نصب داکری بله — OCR با انگلیسی + فارسی نصب است.
- **چندنفره؟** بدون حساب کاربری تک‌کاربره فرضش کنید؛ روی شبکه‌ی غیرمطمئن `UDO_API_KEYS` را ست کنید.
- **سوال فنی؟** [docs/API.md](API.md) و [ARCHITECTURE.md](../ARCHITECTURE.md)
- **باگ؟** Issue گیت‌هاب همان مخزن
