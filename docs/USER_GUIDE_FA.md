# راهنمای کاربر — Universal Document OS (فارسی)

**نسخه:** v4.2.0 · **مخاطب:** کاربر بدون پیش‌زمینه‌ی فنی
**نصب اول؟** [INSTALL.md](../INSTALL.md) را ببینید. این راهنما فرض می‌کند برنامه روی <http://localhost:8000> اجرا شده است.

---

## ۱. این برنامه چه می‌کند؟

فایل می‌دهید، متنش را می‌گیرید — روی کامپیوتر خودتان. مشخصاً:

- **می‌خواند:** PDF، Word (DOCX)، Excel (XLSX)، PowerPoint (PPTX)، OpenDocument (ODT/ODS/ODP)، متن ساده، Markdown، CSV، JSON، HTML و RTF.
- **عکس‌ها را OCR می‌کند** (JPG/PNG/WEBP/TIFF): در نصب داکری موتور Tesseract با زبان انگلیسی + فارسی از قبل نصب است.
- **نشان می‌دهد:** فرمت تشخیص‌داده‌شده، حجم متن، پیش‌نمایش، و تحلیل هوشمند (زبان، جهت متن، نوع سند، تعداد کلمه).
- **تبدیل می‌کند:** خروجی TXT و Markdown از هر سندی؛ HTML رندرشده (با جدول و بلوک کد) از منابع Markdown.
- **به یاد می‌سپارد:** هر آپلود یک رکورد «workroom» + یک ردیف در دیتابیس job + یک خط در audit log.
- **تابلو هوشمند:** در پنل، تب **Dashboard** وضعیت زنده‌ی سیستم را نشان می‌دهد.

چه نمی‌کند (لیست صادقانه): ترجمه از طریق رابط وب، اعلان خودکار پس از پردازش، حساب کاربری. این‌ها در [ROADMAP.md](../ROADMAP.md) هستند.

## ۲. باز کردن برنامه

| صفحه | آدرس | کاربرد |
|---|---|---|
| لندینگ | <http://localhost:8000> | معرفی + لینک پنل |
| پنل | <http://localhost:8000/app> | کار با اسناد + تابلو هوشمند |
| سلامت | <http://localhost:8000/api/health> | چک زنده بودن |

بدون نام کاربری/رمز؛ برنامه محلی است. اگر مدیر سرور `UDO_API_KEYS` را ست کرده باشد، پنل یک‌بار کلید می‌پرسد و در همان مرورگر نگه می‌دارد.

## ۳. پردازش یک سند — قدم‌به‌قدم

1. <http://localhost:8000/app> را باز کنید.
2. فایل را بکشید و رها کنید یا انتخاب کنید (سقف پیش‌فرض ۲۵ مگابایت).
3. عملیات را انتخاب کنید:
   - **analyze** — فقط استخراج متن و تحلیل.
   - **copy** — ساخت فایل قابل دانلود.
4. فرمت هدف: `same` (بدون فایل)، `txt` یا `Markdown`.
5. **Run Job** را بزنید. چند ثانیه بعد می‌بینید:
   - فرمت تشخیص‌داده‌شده، حجم و تعداد کاراکتر،
   - پیش‌نمایش متن،
   - تحلیل هوشمند در نوار وضعیت (زبان/نوع سند/تعداد کلمه)،
   - لینک **دانلود** اگر خروجی ساخته شده باشد.

### تب تابلو هوشمند

آیکون **Dashboard** را در نوار کناری بزنید. همان‌جا زنده می‌بینید:

- نسخه و مدت کارکرد سرویس، تعداد jobها
- موتورهای OCR واقعاً در دسترس یا نه (تیک/ضربدر)
- ماتریس تبدیل‌های ممکن، فرمت‌های قابل استخراج، دسته‌های تحلیل
- شمارش فایل‌ها و حجم واقعی پوشه‌های داده
- وضعیت امنیت (احراز هویت و rate limit روشن است یا نه) + پیشنهادهای اصلاحی

## ۴. پیام‌های رایج

| پیام | معنی | کار |
|---|---|---|
| `[UNSUPPORTED_FORMAT] DOC …` | فرمت legacy (XLS/PPT) یا ابزار کمکی نصب نیست | XLS→XLSX و PPT→PPTX ذخیره کنید |
| `[UNSUPPORTED_FORMAT] IMAGE …` | موتور OCR نصب نیست (فقط در اجرای غیرداکری) | `apt-get install tesseract-ocr tesseract-ocr-fas` یا در داکر اجرا کنید |
| `[EXTRACTION_ERROR] …` | فایل خراب یا رمزدار | رمز را بردارید و دوباره آپلود کنید |
| `content rejected (415)` | محتوا با پسوند هم‌خوان نیست (مثلاً exe با نام pdf) یا zip-bomb است | عمدی نباشد، فایل سالم را بفرستید |
| `file too large (413)` | بیشتر از ۲۵ مگابایت | فایل را کوچک کنید یا `MAX_UPLOAD_BYTES` را در `.env` ببرید |

## ۵. داده‌های من کجاست؟

```
data/uploads/     فایل‌های آپلودی (با نام امن‌شده)
data/outputs/     فایل‌های خروجی txt/md/html
data/workrooms/   یک رکورد JSON برای هر job
data/audit.jsonl  تاریخچه append-only همه کارها
data/jobs.db      دیتابیس SQLite وضعیت jobها
```

هیچ‌کدام به اینترنت نمی‌رود. بکاپ کامل واقعی = `./backup.sh` (شامل همه‌ی `data/`؛ مقدارهای رمزی `.env` در بکاپ سانسور می‌شوند؛ آخرین ۷ بکاپ نگه داشته می‌شود).

## ۶. روتین روزانه

```bash
./start.sh     # صبح: روشن
./status.sh    # وضعیت + شمارنده‌های زنده
./logs.sh      # لاگ زنده
./stop.sh      # شب: خاموش
./update.sh    # آپدیت (اول بکاپ خودکار می‌گیرد)
./backup.sh    # بکاپ واقعی از data/
./smoke-test.sh # تست سرتاسری واقعی: آپلود → استخراج → دانلود
```

ویندوز: فایل‌های `.bat` هم‌نام.

## ۷. سوالات پرتکرار

**از موبایل؟** روی همان Wi-Fi: `http://IP-کامپیوتر:8000/app`. پنل PWA هم دارد — از منوی مرورگر «Add to Home screen» بزنید.

**محدودیت حجم؟** بله، ۲۵ مگابایت پیش‌فرض؛ با `MAX_UPLOAD_BYTES` در `.env` قابل تغییر.

**آپلودم جایی فرستاده شد؟** نه. پردازش کاملاً محلی است.

**عکس اسکن‌شده؟** در نصب داکری بله — OCR با زبان `eng+fas` انجام می‌شود. اگر در اجرای دستی OCR ندارید، پیام راهنما می‌گیرید.

**چرا دانلود ۴۰۴ داد؟** فایل‌های خروجی در `data/outputs/`‌اند؛ اگر حذف شده باشند یا نام اشتباه باشد، امناً ۴۰۴ می‌گیرید.

**چندنفره؟** بدون حساب کاربری، تک‌کاربره فرضش کنید؛ روی شبکه‌ی غیرمطمئن حتماً `UDO_API_KEYS` را ست کنید.
